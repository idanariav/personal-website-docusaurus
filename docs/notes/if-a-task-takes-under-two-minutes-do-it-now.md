# The 2 minute rule

## Notes

### Claim
if you can do this task in under 2 minutes, do it now.

### Explanation
This is meant as an alternative to prioritizing tasks [Group similar tasks to reduce switching costs](/notes/group-similar-tasks-to-reduce-switching-costs.md). Instead of spending time processing this task, there are simply cases where it is more efficient to directly do it rather than postpone it.  [Perfect is the enemy of good](/notes/perfect-is-the-enemy-of-good.md).

### Why it matters
A task left open still costs something just by sitting there, and small problems left alone tend to grow into bigger ones [Handle problems while they are still small](/notes/handle-problems-while-they-are-still-small.md). There's also a Parkinson's law angle to it - a task expands to fill whatever time we give it [A task takes as much time as you give it](/notes/a-task-takes-as-much-time-as-you-give-it.md), so giving it none is sometimes the fastest way through.
