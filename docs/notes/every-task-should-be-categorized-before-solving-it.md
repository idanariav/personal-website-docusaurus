# Task Sorting

## Notes

### Claim
every task should be divided into one of four categories in order to find the best solution to solving it

### Explanation
How to sort a task:
1. *Delete* - is the task even worth doing? is it beneficial or important? otherwise - delete it,
2. *Delay* - is it important to do it now? also - consider the "2 minute rule". else, delay it [If a task takes under two minutes do it now](/notes/if-a-task-takes-under-two-minutes-do-it-now.md)
3. *Delegate* - is it worth your time? imagine you evaluate your time as an hourly rate of income. does this task justifies this cost [Pricing your time reveals when to delegate](/notes/pricing-your-time-reveals-when-to-delegate.md)? otherwise, try to delegate it to a person (for exp - finding someone to fix a leak in the house, repair the car...) [Delegating production trades control for efficiency](/notes/delegating-production-trades-control-for-efficiency.md). also, another possibility is to delegate it to an automation process. try to see if this recurring task can be partially done by a software/code/tool you set-up [Automation extends delegation beyond people](/notes/automation-extends-delegation-beyond-people.md)
4. *Do* - if all else fails, just do the task
